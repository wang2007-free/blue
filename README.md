# 红船文创 · 扫码介绍页

一个纯静态的单页介绍页：手机扫码打开后显示 **项目名称 / 团队名称 / 视频介绍**。
不需要后端、不需要数据库，任何静态托管（GitHub Pages、Gitee Pages、Vercel、学校服务器）都能放。

```
redboat-site/
├── index.html          ← 页面本体（文字都在这里改）
├── assets/
│   ├── cover.jpg       ← 视频封面 / 分享缩略图
│   ├── favicon.svg     ← 浏览器标签小图标
│   ├── qr-preview.png  ← 临时二维码（指向本机局域网，仅调试用）
│   └── intro.mp4       ← 视频（已放入，720p / 1 分 31 秒 / 约 15MB）
├── tools/
│   └── make_qr.py      ← 用网址生成二维码（PNG + SVG）
└── README.md
```

---

## 1. 先把文字换成你们的

用记事本 / VS Code 打开 `index.html`，搜索 `修改这里`，一共三处：

| 位置 | 现在的内容 | 说明 |
| --- | --- | --- |
| `<h1>` | 红船文创 · 初心印记 | 项目名称，建议 8～12 个字，太长会自动换行 |
| `.team` | 红船文创团队 | 团队名称 / 学校 + 团队 |
| `.lede` | 以红船精神为内核…… | 一句话简介，30 字左右最好看 |

另外这几处也可以顺手改：

- `<title>` 和 `og:title`：手机浏览器标签、微信分享卡片上的标题；
- `.eyebrow`：标题上方的小字（现在是“红色文化创意产品”）；
- `.chips` 三个标签：红船精神 / 文创设计 / 青年表达；
- `.brand` 里的“红色文创 · 红船文化”；
- 页脚“扫码进入 · 红色文创项目”。

> 只改文字，不要动 `<style>` 和 `<script>` 里的内容。

## 3. 本地预览

直接双击 `index.html` 就能看；想在手机上先看效果，在 `redboat-site` 目录执行：

```bash
python -m http.server 8099
```

然后手机连同一个 Wi-Fi，访问 `http://电脑的局域网IP:8099/`。
（Windows 首次运行可能弹防火墙提示，选“允许访问”。）

## 4. 上线（三选一）

### 方案 A：GitHub Pages（免费、最常用）

1. 注册 <https://github.com>，新建一个 **Public** 仓库，例如 `redboat`；
2. 把 `index.html` 和整个 `assets` 文件夹拖进仓库页面上传，提交；
3. 进入仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存；
4. 等 1～2 分钟，地址是：`https://你的用户名.github.io/redboat/`。

> 国内访问 GitHub Pages 有时偏慢，答辩现场建议提前缓存或改用方案 B。

### 方案 B：Gitee Pages（国内快，需实名）

1. 注册 <https://gitee.com> 并完成实名认证；
2. 新建公开仓库，上传同样两个东西；
3. 仓库 **服务 → Gitee Pages**，选择分支、勾选强制 HTTPS，启动；
4. 地址形如 `https://你的用户名.gitee.io/redboat/`。

### 方案 C：Vercel / Netlify（拖拽即上线）

登录后把整个 `redboat-site` 文件夹拖进去，几十秒后会得到一个 `https://xxx.vercel.app` 的地址。

无论哪种，**拿到网址后先自己在手机流量下打开确认一次**（不要只用 Wi-Fi，避免打不开时误判）。

## 5. 生成二维码

拿到最终网址后，在 `redboat-site` 目录执行：

```bash
pip install segno
python tools/make_qr.py https://你的网址
```

会得到 `qr.png`（约 1200px，够打印和投屏）和 `qr.svg`（矢量，印刷用）。

可选参数：

```bash
python tools/make_qr.py https://你的网址 --name qr-final --color "#8c1418"
```

`--color` 换成品牌红也能量出来，但**打印或远距离扫码建议用默认纯黑**，识别率最高。

## 6. 几个坑

- **二维码扫不开**：90% 是网址还不能公网访问（比如填了 `localhost`、`192.168.x.x`、`file://`）。二维码里必须是任何人用手机流量都能打开的地址。
- **视频不播**：优先检查是不是 H.264 的 MP4；`.mov`、`.avi`、HEVC 编码在部分安卓机上不兼容。
- **微信里打不开**：微信内置浏览器对部分域名有限制，可点右上角“在浏览器打开”；正式场合建议用系统相机扫码。
- **改了文字没生效**：托管平台有缓存，等 1 分钟或强制刷新（手机端清缓存）。
- **二维码太密扫不出**：网址越长，码越密。尽量用短路径（如 `/redboat/`），不要带一长串参数。
